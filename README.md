# 100 Jaguares Dijeron - Sistema Web Producción

Este paquete contiene todo lo necesario para subir y poner en funcionamiento el sistema en la nube (GitHub Pages, Vercel, Netlify o cualquier hosting web).

## 🚀 Despliegue en GitHub Pages (en 3 pasos):
1. Sube los archivos de esta carpeta (`index.html`, `bg_plantilla.png`, `logo.png`) a un repositorio en GitHub.
2. En GitHub, ve a **Settings** > **Pages**.
3. En **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`, luego da clic en **Save**.
4. En 1 minuto tendrás tu enlace activo:
   - **Pantalla Inicial:** `https://tu-usuario.github.io/tu-repositorio/`
   - **Proyector Directo:** `https://tu-usuario.github.io/tu-repositorio/#projector`
